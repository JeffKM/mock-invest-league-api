# 04. 1주차 할 일

> 끝났다는 기준: **매수·매도 API가 Swagger(`/swagger-ui.html`)에서 동작하고, 불변식 테스트가 통과한다.**
> 규칙: 엔티티·주문 서비스·트랜잭션 코드·테스트는 **직접** 짠다. 막히면 답이 아니라 힌트만 찾아본다.

## 이미 되어 있는 것(뼈대)

- `build.gradle`(Spring Boot 3.5.7, Java 17, JPA, Flyway, Testcontainers, springdoc, JaCoCo)
- `docker-compose.yml`(로컬 PostgreSQL, 포트 5433)
- `V1__init.sql` 스키마, `V2__seed_companies.sql` 가상 상장사 24개
- `common`: `ApiResponse<T>`, `ErrorCode`, `BusinessException`, `GlobalExceptionHandler`, `Clock` 빈
- 앱 기동 테스트 1개(도커 필요)

### 1. 엔티티(1일) — 완료(ROADMAP 8·10단계)
- [x] `company/Company` — 가장 쉬운 것부터. `@Enumerated(EnumType.STRING)` 으로 `Volatility`
- [x] `contest/Contest`, `account/Participant`, `account/Holding`(복합키 → `@IdClass` 또는 `@EmbeddedId` 중 고르고 이유 적기)
- [x] `order/Order`(테이블 이름이 `orders`인 이유: `order`는 SQL 예약어), `account/CashLedger`
- [x] 앱 기동 → `ddl-auto: validate` 가 통과하면 엔티티와 스키마가 맞은 것

> 힌트: 연관관계는 처음엔 `@ManyToOne(fetch = LAZY)`만 쓰고 양방향은 만들지 않는다. 필요해질 때 추가한다.

### 2. 순수 도메인 로직 + 단위 테스트(1일, DB 없이)
- [ ] 수수료 계산(I4): `fee(amount, feeBp)` — 원 미만 버림. 경계값 테스트(0원, 199원, 큰 금액 오버플로)
- [x] `Participant.withdraw(amount)` / `deposit(amount)` — 부족하면 `BusinessException(INSUFFICIENT_CASH)` (I1)
- [x] `Holding.decrease(qty)` — 부족하면 `INSUFFICIENT_QUANTITY` (I2)
- [ ] 장 시간 판단(I9): `Clock`을 받아 "지금 장 중인가" — `Clock.fixed`로 09:00, 15:29, 15:30 테스트

### 3. 시장가 주문(2일)
- [ ] 1주차는 가격 엔진이 없으므로 **임시 현재가 = `contest_listings.base_price`** (3주차에 틱 가격으로 교체)
- [ ] `POST /api/contests/{contestId}/participants` 참가(초기 자금 + `INITIAL` 원장 1줄)
- [ ] `POST /api/contests/{contestId}/orders` 시장가 매수·매도, 헤더 `X-User-Id`, `Idempotency-Key`
- [ ] `OrderService.placeMarketOrder` 하나의 `@Transactional` 안에서: 검증 → 잔고·보유 변경 → 주문 저장 → 원장(`BUY`/`SELL`, `FEE`) 저장
- [ ] `GET /api/contests/{contestId}/me` 내 현금·보유·평가액

> 생각해 볼 것(2주차 "왜" 노트 재료): 지금 코드는 잔고를 읽고 → 계산하고 → 저장한다. 같은 계좌로 요청 두 개가 동시에 오면 어떻게 될까? 일부러 아직 막지 않는다.

### 4. 통합 테스트(1일, Testcontainers)
- [ ] 매수 후 현금 = 초기 자금 − 금액 − 수수료
- [ ] 잔고보다 큰 매수 → 409 `INSUFFICIENT_CASH`, 잔고 그대로
- [ ] 보유보다 많은 매도 → 409, 보유 그대로
- [ ] I5: 여러 번 사고판 뒤 `cash + reserved_cash = Σ 원장`(참가 때 남긴 INITIAL 포함)
- [ ] 같은 `Idempotency-Key` 두 번 → 주문 1건, 같은 응답(I6). 1주차는 "순차로 두 번"만. 동시에 두 번은 2주차
